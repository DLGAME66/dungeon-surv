## 📁 项目结构

```

├── client/

├── server/
```

## 🚀 快速开始

### 方式一：联机模式（推荐）

**1. 启动服务器：**
```bash
cd server
npm install        # 首次安装依赖
node server.js     # 启动服务器（端口3001）
```

**2. 打开游戏：**
在浏览器中打开 `client/index.html`

> ⚠️ 如果客户端和服务器在不同机器，需要修改 `client/index.html` 中的 `SERVER_URL` 变量，改为服务器IP地址，例如：
> ```javascript
> const SERVER_URL = 'http://192.168.1.100:3001';
> ```

---

### 方式二：断网/单机模式

直接用浏览器打开 `client/index.html`，点击「**离线模式**」即可游玩，无需启动服务器。

## 📱 跨平台说明

| 设备 | 支持方式 |
|------|---------|
| **电脑** | Chrome/Edge/Firefox 直接打开 index.html |
| **手机** | 同上，通过浏览器访问 |
| **平板** | 同上，推荐使用Chrome/Safari |
| **局域网联机** | 手机/平板通过电脑IP访问服务器 |

### 📂 部署到服务器（可选）

将 `client/` 文件夹部署到任意静态托管（GitHub Pages、Vercel、Nginx等），或用简单命令：

```bash
# 使用 Node.js 静态服务器
npx serve ./client -p 8080

# 或 Python
python -m http.server 8080
```

## 🎯 游戏玩法

### 角色职业

| 职业 | 生命 | 攻击 | 防御 | 技能 |
|------|------|------|------|------|
| ⚔️ 战士 | 130 | 12 | 8 | 🗡 重击（200%伤害） |
| 🔮 法师 | 80 | 18 | 3 | 🔥 火球（范围攻击） |
| 🗡 刺客 | 90 | 16 | 5 | 💀 背刺（300%暴击） |
| ✨ 牧师 | 100 | 8 | 6 | 💚 治疗（恢复40HP） |

### 操作方式

**电脑：** 方向键/WASD移动，鼠标点击施放技能
**手机/平板：** 屏幕D-Pad方向按钮移动，点击技能后点击地图施放

### 游戏流程

1. 输入名字 → 创建/加入房间
2. 选择英雄职业 → 点击「准备」
3. 房主点击「开始游戏」
4. 在地牢中移动、战斗、拾取道具
5. 击杀所有怪物后，走上楼梯进入下一层
6. 挑战更深的楼层，比拼存活和等级！

### 联机功能

- 🏠 创建房间（生成6位房间码）
- 🚪 加入房间（输入房间码）
- 💬 实时聊天
- 👥 最多4人同屏
- 🔄 断线重连保护（玩家断线后房间保留）

## 🔧 部署到云服务器

如果想和朋友跨地域联机，需要一台有公网IP的服务器：

```bash
# 在服务器上
cd server
npm install
node server.js

# 将 client/index.html 中的 SERVER_URL 改为你的服务器IP
# 例如: const SERVER_URL = 'http://你的服务器IP:3001';
```

然后将修改后的 index.html 部署到静态托管，分享链接给朋友即可。

## 🎨 技术架构

- **游戏引擎：** Phaser 3（HTML5 Canvas）
- **联机通信：** Socket.IO（WebSocket + HTTP轮询）
- **服务器：** Node.js + Express
- **断网存储：** LocalStorage（可扩展）
- **美术资源：** Emoji字符（零外部依赖）

## 📋 已知问题 & 限制

1. 地牢地图为程序化随机生成，偶尔可能出现无法到达的房间（概率极低）
2. 离线模式目前仅支持单人，多人断网需要每人在各自设备打开
3. 手机端技能施放需要先点「技能」按钮，再点地图目标格子
4. 服务器默认端口3001，如需修改请改 `server/server.js` 最后一行的 `PORT`
